Getting Started

You can install ClimaRivers using Julia's built-in package manager.

Julia version requirement

ClimaRivers requires Julia 1.10 or higher. Check your version with julia --version, or download the latest release from https://julialang.org/downloads/.

Installation

Install ClimaRivers from the Julia package manager:

using Pkg
Pkg.add("ClimaRivers")

To load the package in a Julia session:

using ClimaRivers

Cloning the repository

If you want to develop or contribute to ClimaRivers, clone the repository and register it as a development package:

git clone https://github.com/CliMA/ClimaRivers.jl
cd ClimaRivers.jl
using Pkg
Pkg.develop(path = ".")

Running the test suite

To verify your installation, run the package tests:

using Pkg
Pkg.test("ClimaRivers")

Building the documentation locally

First instantiate the docs environment, then run the build script:

julia --project=docs/ -e 'using Pkg; Pkg.instantiate()'
julia --project=docs/ docs/make.jl
